# Support

watx is an evolving WebAssembly MVP implementation. Its interpreter, native
JIT, binary reader, and platform-specific paths are under development; behavior
and availability may differ between targets. No production support or response
time is guaranteed.

For a reproducible defect, use the repository's GitHub issue tracker and include
the commit or release, operating system and architecture, the command used, and
the smallest input that reproduces the problem. Remove secrets and private data
before sharing an input file.

For a feature request, describe the use case and expected behavior. General
questions can be raised in an issue when no discussion area is available.
Security concerns should follow [SECURITY.md](SECURITY.md); do not post exploit
details in a public issue.
